# ویدیوهای آموزشی پیشخوان

ساخت خودکار ویدیوی آموزشی گفتاری از پیشخوان وردپرس: Playwright صفحه را مثل یک ارائه‌دهنده کار می‌کند
(نشانگر نرم، هایلایت قبل از کلیک، تایپ طبیعی)، edge-tts متن هر مرحله را با صدای فارسی می‌خواند و
ffmpeg همه را با اینترو و اوترو برند، زیرنویس و صدای یکنواخت کنار هم می‌گذارد.

## ایمنی سایت اصلی
- همه‌ی درخواست‌های غیر GET (ذخیره، ذخیره‌ی خودکار، انتشار، آپلود، حذف) داخل مرورگر مسدود می‌شوند
  (`lib/safety.js`). heartbeat وردپرس یک پاسخ ساختگی می‌گیرد تا پیام «اتصال قطع شد» نیاید.
- دکمه‌های «انتشار» و «تعیین تصویر شاخص» فقط هایلایت می‌شوند.
- تنها اثر جانبی: وردپرس با باز شدن «افزودن نوشته» یک پیش‌نویس خودکار (auto-draft) می‌سازد که
  در فهرست نوشته‌ها دیده نمی‌شود و خود وردپرس بعد از ۷ روز پاکش می‌کند.
- `auth.json` (کوکی نشست) هرگز commit یا چاپ نمی‌شود.

## اجرا
```bash
./setup.sh                      # یک بار: وابستگی‌ها، edge-tts، فونت وزیرمتن
npm run selftest                # آزمون کل زنجیره روی یک صفحه‌ی محلی (بدون سایت)
WP_USER=… WP_PASS=… node login.js   # یا متغیرها را در تنظیمات محیط بگذارید
node inspect.js                 # بررسی فقط‌خواندنی صفحه‌ی «نوشته جدید»
python3 tts.py new-post         # صدای هر مرحله + مدت‌ها (تغییرنکرده‌ها از کش)
node record.js new-post         # ضبط 1920x1080
node render.js new-post         # output/new-post/new-post.mp4 و .srt و -subtitled.mp4
```

## تلفظ
اگر صدا کلمه‌ای را اشتباه خواند (اعراب، کسره‌ی اضافه، محاوره‌ای‌ها مثل «رو»)، آن را به
`branding/pronunciation.json` اضافه کنید، مثلاً `"مطلب": "مَطلَب"` یا `"عنوان مطلب": "عنوانِ مَطلَب"`.
این املا فقط به صدا داده می‌شود؛ زیرنویس همان متن سناریو را نشان می‌دهد. فقط مراحل تغییرکرده دوباره ساخته می‌شوند.

## وضعیت فعلی و قدم بعد
1. `WP_USER` و `WP_PASS` در تنظیمات محیط ابری ثبت شوند (کاربر موقت با نقش «ویرایشگر»).
2. `node login.js` ← `node inspect.js` و تطبیق `scenarios/new-post` با صفحه‌ی واقعی.
3. تأیید سناریو توسط صاحب پروژه، سپس `tts.py` ← `record.js` ← `render.js`.

## ویدیوی جدید
یک پوشه در `scenarios/<نام>/` با دو فایل بسازید:
- `scenario.md`: برای هر مرحله `## <شناسه> · <عنوان>` و خطوط «کار روی صفحه»، «عنصر هدف» و «گفتار».
- `steps.js`: برای هر شناسه یک تابع که با `d.point`، `d.click`، `d.type` و `d.highlight` صفحه را کار می‌کند.

ظاهر برند (رنگ، لوگو، متن اوترو، صدا، سرعت) در `branding/config.json` است و برای همه‌ی ویدیوها یکسان می‌ماند.
لوگو را در `branding/logo.png` (یا svg) بگذارید؛ اگر نباشد نام برند نوشته می‌شود.
